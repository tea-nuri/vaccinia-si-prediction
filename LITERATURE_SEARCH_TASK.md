# ТЗ: поиск внешних данных VACV

Найди первичные публикации и приложения с экспериментальными измерениями для предсказания SI VACV. Репозиторий: https://github.com/tea-nuri/vaccinia-si-prediction. Сначала подтяни изменения, прочитай AGENTS.md, LITERATURE_LEADS.md и уже собранные DOI в data/.

## Приоритеты

1. Полные таблицы и схемы: 10.2174/1573406419666221125101053 (кумаринилимидазолы), 10.1007/s11094-019-1907-9 (полициклические амидоимиды), 10.1007/s11094-017-1629-9 (мочевины/тиомочевины), 10.1002/cbdv.201800153 (борнеол/камфора), 10.1039/D5NJ03203B (арилэтенилимидазолы).
2. Недостающие таблицы: 10.1002/cmdc.201000306 (Table 1 отсутствует в PMC), 10.1128/JVI.00770-07; приложения диссертации Samolej 2019, UCL eprint 10084542.
3. Для 10.1099/jgv.0.001971 полная Table 2 найдена: проверить структуры 12 сердечных гликозидов, стереохимию и контекст HeLa / Western Reserve.

Не дублируй уже включённые таблицы 10.1007/s11172-019-2467-6 и 10.3390/molecules27154761. Для остальных DOI проверь существующие данные. Ищи у издателей, в PMC, Supporting Information, авторских и университетских архивах, исходных таблицах патентов. Обзоры нужны для перехода к первоисточнику. Запросы: DOI + supporting information; название + full text; vaccinia + класс соединений + cytotoxicity + selectivity index.

## Извлечение

На строку: DOI, название/год, URL PDF и приложения, страница/таблица, номер соединения, проверенный изомерический SMILES, исходные IC50/EC50 и CC50/TC50/MCC с единицами и отношением (=, >, <), опубликованный SI, отдельно рассчитанное отношение, NA/NT, клеточная линия, штамм, длительность и endpoint. Для структур сохраняй источник, CID/InChI при наличии, соли, таутомеры, абсолютную стереохимию и E/Z; сверяй формулы с экспериментальной частью.

NA, NT и пустой SI различаются. Границы не являются точными значениями. EC50 не переименовывай в IC50, MCC — в CC50. Данные других вирусов не смешивай с VACV. Противоречия между статьями сохраняй отдельно с контекстом, не усредняй. Не восстанавливай структуру и не выбирай источник по целевой метке соревнования. Концентрации соревнования и их пропуски не используй; для покрытия допустимы SMILES, strain, Culture.

## Результат

Передай список проверенных источников с приоритетами и ссылками; CSV фактов с происхождением каждой строки; неоднозначности и недоступные приложения. Для проверенных структур посчитай точные совпадения со стереохимией и подходящим контекстом: отдельно новые и уже покрытые. Укажи три лучших следующих источника и число реально проверенных записей. Прирост Public Score без измерения не обещай.

Работай в research/literature_<name>/ или отдельной ветке. Код модели, сабмиты и выбранные результаты не меняй; в Kaggle не отправляй. Перед коммитом и push подтяни изменения команды; без force push.
