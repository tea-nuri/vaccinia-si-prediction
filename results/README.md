# Текущий кандидат для исправленной задачи

Используйте **submission_corrected_v2.csv**. Версия данных, SHA-256 и статус отправки записаны в `corrected_export.json`; рабочая конфигурация — в `corrected_selection.json`.

Остальные submission/candidate CSV и отчёты без префикса corrected относятся к старой версии v1 с ошибочной меткой SI=10000 для неактивности. Не используйте их как текущий сабмит. Старые численные Public Score были пересчитаны после исправления организаторами.
