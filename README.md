# VACV SI — команда «Чай»

Предсказание индекса селективности по SMILES для [соревнования Kaggle](https://www.kaggle.com/competitions/molecular-activity-prediction-hack). Выбрана лучшая подтверждённая версия **V4 Степана**: **Public MSE 5 154 554.48738**, подтверждён 6 ноября 2026. Её неизменённый CSV — `results/submission.csv` (на Kaggle назывался `submission_v4.csv`). Чем меньше MSE, тем лучше.

## Воспроизведение

Проверено на Python 3.12; точные версии библиотек указаны в `requirements.txt`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python collect_data.py --offline
python -m unittest test_validation.py -v
python train.py --output run
```

Обучение и проверка создают в `run/`: `submission.csv`, `model.joblib`, `training_used.csv`, `validation.csv`, `metrics.json`. CSV готов к загрузке на Kaggle. Быстрый запуск без повторной кросс-валидации: `python train.py --skip-cv --output run`. Тест воспроизводимости сравнивает все 597 предсказаний с выбранным сабмитом.

Обновление внешних данных из интернета: `python collect_data.py --refresh`. Обычный запуск работает без сети благодаря сохранённому снимку ChEMBL. Команда `--offline` восстанавливает базу и повторяет её проверку из этого снимка.

## Модель и проверка

Исходная строка SMILES преобразуется в символьные n-граммы длины 2–6, TF-IDF с сохранением регистра и sublinear TF; первый регрессор — Ridge, alpha=0.03. Его прогноз имеет вес 85%; ещё 15% даёт ExtraTrees (500 деревьев, seed 42) по длине строки и количествам/позициям символов SMILES. Затем применяется `clip((prediction - 5000) * 1.5 + 5000, 0, 10000)`. Оба компонента используют только SMILES. CC50, IC50, их пропуски и остальные колонки не входят в признаки.

Обучающая цель ограничена сверху 10 000, прогнозы — диапазоном 0–10 000. **MSE считается по исходным, не обрезанным целям.** Словарь и IDF обучаются внутри каждого fold. Повторы канонических молекул не пересекают train и validation.

| Проверка | MSE |
|---|---:|
| GroupKFold, seed 42 | 7 137 807 |
| GroupKFold, seed 2026 | 7 100 840 |
| GroupKFold, seed 117 | 6 582 681 |
| GroupKFold, seed 2027 | 7 153 205 |
| GroupKFold, seed 7 | 7 665 567 |
| Среднее пяти разбиений | 7 128 020 |
| Scaffold GroupKFold | 11 197 739 |
| Kaggle public | 5 154 554.48738 |

Модель и параметры выбраны на этом небольшом наборе, поэтому CV оптимистична. Исходная запись SMILES отражает соглашения источника; эквивалентные записи могут получать разные прогнозы. Ограничение цели может занижать действительно высокие SI. Public score не является оценкой скрытой части теста.

## Внешние данные

Сборщик использует две публикации: [10.1039/d4md00181h](https://doi.org/10.1039/d4md00181h) и [10.1016/j.ejmech.2023.115601](https://doi.org/10.1016/j.ejmech.2023.115601). Собраны 63 записи, 57 проходят формальные проверки, 39 уникальных SMILES среди допущенных записей. Готовая база хранится одним CSV; подходящие записи отмечены `usable_for_training`.

Сохраняются клеточная линия, штамм, время, отношения измерений, assay/activity ID и DOI. Опубликованный SI не подменяется автоматически вычисленным отношением: CC50/IC50 служит проверкой согласованности. Границы `>`/`<` не превращаются в точные значения; EC50 не переименовывается в IC50; неоднозначные пары вызывают ошибку. Для публикации 2023 года сохранена разница времени измерений CC50 (72 ч) и IC50 (96 ч).

**Выбранная лучшая модель обучена только на 320 исходных строках.** Внешняя база передаётся по ТЗ, но не добавлена в её обучение: прежняя проверка добавления этих данных ухудшала качество. Фактический состав обучения зафиксирован в `results/training_used.csv`.

Репозиторий приватный, поскольку содержит данные соревнования; организаторам нужен доступ для проверки. Эти условия не распространяются автоматически на данные соревнования.
