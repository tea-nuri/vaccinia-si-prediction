## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python train.py --output run_v2
```

Текущая конфигурация задаётся `results/corrected_selection.json`. Команда запускает все три scaffold- и восемь molecular-протоколов, обучает модель и сохраняет:

- `run_v2/submission.csv` — 597 предсказаний в порядке официального sample;
- `run_v2/training_used.csv` — фактически использованные признаки и исправленные метки;
- `run_v2/metrics.json`, `oof_*.csv` — MSE, MAE и разбиения валидации;
- `run_v2/export.json` — версия задачи, конфигурация и контрольные суммы;
- `run_v2/model.joblib` — локальный обученный артефакт, который не добавляется в Git.

Быстрое воспроизведение предсказаний без CV:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python train.py --skip-cv --output run_v2_replay
python -m unittest test_corrected_pipeline -v
```

`corrected_pipeline.py` содержит рабочую регрессию. `train.py` передаёт управление этому модулю; прежние вспомогательные функции в нём сохранены для исторических экспериментов.

## Признаки и валидация

Модель получает только SMILES, strain и Culture. Концентрации из конкурсных train/test, их пропуски, Title и index не являются признаками. Используются Morgan fingerprints, дескрипторы RDKit и категориальный контекст; отдельные исследовательские варианты используют текст SMILES или Tanimoto kernel.

В каждом фолде словарь, кодирование категорий, заполнение пропусков и регрессор обучаются только на тренировочной части. Molecular-протоколы исключают одинаковые канонические молекулы; scaffold-протоколы исключают целые каркасы. Таргеты при подсчёте MSE не ограничиваются сверху и не логарифмируются. Большая обучающая метка 36066.667 остаётся в общей метрике; её влияние показывается отдельно. Повторные разбиения тех же 320 строк не являются независимым датасетом.

В новой задаче нет классификатора `SI == 10000`, принудительной подстановки 10000 для неактивности и прямого подставления литературного ответа для test. Старые OOF, модели и метрики не используются для выбора исправленного регрессора.

## Результат локальной проверки

У фиксированного исходного регрессора Random Forest с log1p-преобразованием таргета средняя сырая MSE на трёх scaffold-протоколах **4 286 609.68**, MAE **210.19**. На первых пяти molecular-протоколах MSE **4 274 835.10**, MAE **210.30**; на дополнительных трёх MSE **4 268 207.52**, MAE **207.16**. Около 95% SSE приходится на крупнейшую метку, которая остаётся в отчёте. Среди десяти CPU-вариантов и трёх GPU-вариантов TabPFN нет модели с подтверждённым существенным преимуществом над фиксированным исходным регрессором. Это исправление версии задачи; выигрыш от изменения архитектуры не заявляется.

По сравнению с прогнозами прежней отправленной модели, оценёнными на исправленных метках, локальная MSE уменьшилась на 13,8–20,1 млн на всех 11 разбиениях. Такой анализ проверяет устранение ошибки кодировки и не заменяет оценку Public. Отчёты: `corrected_discovery.json`, `corrected_gpu_discovery.json`, `corrected_legacy_comparison.json` в results.

## Внешняя база

По уточнению организаторов, переданному пользователем, **нельзя использовать внешние IC50/CC50 для молекул из test**, а также нельзя обучаться на test. Можно собирать дополнительные данные других молекул из открытых источников. У существующей базы сохранены DOI, URL, отношения измерений, исходные снимки и их контрольные суммы.

```bash
python collect_data.py --offline
python collect_training_v2.py
```

Первая команда воспроизводит историческую исходную базу из проверенных снимков. Вторая создаёт `data/external_training_v2.csv` и отчёт фильтрации. Из обучающего внешнего пула исключаются все молекулы официальных train и test по нейтрализованной связности основной компоненты, включая другие стереоизомеры и соли. Это строже запрета на test и исключает попадание валидационных ответов через внешнюю базу. Неоднозначные внешние значения также исключаются. Связанные CC50/IC50 используются только из явно сопоставленных экспериментов; случайные измерения не объединяются в отношение.

В отфильтрованном пуле 24 молекулы: 23 с измерениями и одна с явной отметкой неактивности. Для последней `model_target=0` отражает исправленное условие задачи; поле измеренного SI не заполняется вымышленным числом. Текущая основная регрессия пока обучается только на официальных 320 строках; наличие внешней базы не означает её автоматическое включение в обучение. Дополнительное обучение допускается после проверки на тех же протоколах с исключением валидационных каркасов.

Дополнительный исследовательский пул `data/external_training_candidate_v3.csv` содержит **60 записей**: исходные 24, ещё 23 опубликованных точных SI из четырёх документов ChEMBL и 13 SI из таблицы 1 статьи DOI `10.3390/v18010071`. Для новых структур из статьи сохранены систематические названия, страницы авторского приложения и проверенные ответы OPSIN. Все официальные train/test parent-структуры исключены. Данные воспроизводятся из 24 снимков открытых источников; повторный сбор с пустым кэшем дал побайтно одинаковый CSV.

```bash
python collect_external_candidate_v3.py
# После первого сбора можно использовать проверенные локальные снимки:
python collect_external_candidate_v3.py --offline
python -m unittest test_external_candidate_v3 -v
```

В новой статье некоторые клетки CC50 содержат значения для нескольких сроков. Они не образуют однозначную пару с EC50, поэтому в этих строках используется явно опубликованный точный SI, а числовой CC50 остаётся пустым. Две строки с нижними границами SI исключены из точечных меток. Десятичная запятая обрабатывается явно. Исходный текст и причина исключения сохраняются в отчёте; границы не подменяются равенством.

## Диагностика большой ошибки и дополнительные проверки

На исходном scaffold-разбиении семь строк с SI ≥ 1000 дают 99,57% SSE. Средний прогноз для них составляет 32,10 при среднем SI 7814,74. Это наблюдаемое локальное занижение больших таргетов; распределение скрытой ошибки Kaggle неизвестно. Влияние крупнейшей строки остаётся в полной MSE.

Проверены ещё 30 конфигураций на всех 11 протоколах: нормализация написаний Culture/strain, разные молекулярные представления, соседние молекулы и внешнее обучение на 60 записях. Лучшее среднее scaffold MSE для новых представлений — 4 279 776,62; для внешнего пула — 4 283 057,15. Выигрыш относительно фиксированной модели составляет 0,159% и 0,083%; ни один кандидат не прошёл заранее заданный порог существенного улучшения. Выбранная модель и Kaggle-файл сохраняют прежнюю конфигурацию. Новых отправок эта серия не потребовала; последний подтверждённый Public MSE — **2 002 039,13858**.

```bash
python train.py --models rf_log --all-splits --output run_reference
python experiments/evaluate_corrected_representations.py --reference run_reference --output run_representations
python experiments/evaluate_corrected_external.py --reference run_reference --output run_external60
```

Полные метрики и параметры этой серии находятся в `results/corrected_context_representations_*.json` и `results/corrected_external_2026_validation_*.json`; выводы и ограничения — в `results/corrected_error_audit.json`. Численно повторяющиеся разбиения не являются независимыми наборами данных.

## История и отправки

`data/train.csv`, прежние файлы в `results/`, `experiments/` и прежние тесты сохранены как история версии v1. Они могут содержать прежнюю кодировку неактивности и старые литературные подстановки. Для текущей работы используется `train_v2.csv` и исправленный entrypoint, описанный выше.

Готовые значимые изменения публикуются в приватный GitHub команды. Kaggle-сабмит допускается только при сильных основаниях ожидать снижение текущего пересчитанного Public MSE хотя бы на миллион. Локальная MSE сама по себе не гарантирует такое снижение.
