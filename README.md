# VACV selectivity index prediction — команда «Чай»

Решение [Molecular Activity Prediction](https://www.kaggle.com/competitions/molecular-activity-prediction-hack): предсказание индекса селективности SI по SMILES. Официальная метрика — MSE в исходной шкале, меньше — лучше.

Проверенный public score `submission_v3.csv`: **5 351 782.35466**. Версия `submission_v2.csv` получила 10 060 443.90200, первая версия — 10 903 744.73108. Public leaderboard использует примерно 30% теста и не является финальной оценкой.

## Быстрый запуск

Проверено на Python 3.14.5, зависимости зафиксированы в `requirements.txt`.

```bash
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python collect_data.py --offline
python -m unittest test_validation.py -v
python train_text.py --output run_text
```

Результат: `run_text/submission_v3.csv`, `run_text/model.joblib`, `run_text/training_used_text.csv`, `run_text/oof.csv`, `run_text/metrics.json`. Только обучение и предсказание без повторной CV: `python train_text.py --skip-cv --output run_text`.

Предыдущая модель и эксперимент с внешними данными воспроизводятся командой `python train_model.py --external --output run`.

Для новой загрузки открытых данных:

```bash
python collect_data.py --refresh
```

Сетевой доступ нужен только для `--refresh`. В репозитории сохранён `chembl_snapshot.zip`, поэтому обычное воспроизведение не зависит от доступности API. Скрипт проверяет полноту ответов, сохраняет URL и SHA-256 исходных JSON в `sources.json`.

## Текущая модель v3

Используются только исходные строки `SMILES`: символьные фрагменты длины 2–6, TF-IDF с сохранением регистра и sublinear TF, Ridge с `alpha=0.03`. Словарь и IDF обучаются только внутри обучающей части каждого fold. `CC50_uM`, `IC50_uM_VACV`, `Title`, `strain`, `Culture`, `index` не входят в признаки.

Цель при обучении ограничена сверху 10 000; предсказания — диапазоном 0–10 000. Порог выбран по локальной проверке. **Все MSE считаются по исходным, не обрезанным целевым значениям**, включая 36 066.667. В `training_used_text.csv` сохранены исходная и фактическая обучающая цели.

| Проверка | MSE v3 |
|---|---:|
| Canonical GroupKFold, seed 42 | 7 589 982 |
| Canonical GroupKFold, seed 2026 | 7 575 296 |
| Canonical GroupKFold, seed 117 | 7 029 456 |
| Среднее трёх разбиений | 7 398 245 |
| Scaffold GroupKFold, без перемешивания | 10 795 255 |
| Kaggle public | 5 351 782.35466 |

`metrics_text.json` содержит настройки и SHA-256 файлов данных; `validation_text.csv` — out-of-fold прогнозы. `experiments_text.json` фиксирует сравнения с CatBoost, XGBoost, классификацией группы SI=10 000, деревьями и разными текстовыми представлениями. Для выбранной v3 достаточно исходного `requirements.txt`; CatBoost/XGBoost при её воспроизведении не нужны.

Важное ограничение: исходная запись SMILES сохраняет соглашения источника о записи структуры. Канонизация заметно ухудшила локальные результаты; эквивалентные записи одной молекулы могут получать разные ответы. Это модель данного набора, а не доказательство устойчивого переноса между лабораториями. Ограничение цели также может занижать реально высокие SI. Модель и параметры выбраны по этим же небольшим данным, поэтому CV-оценка оптимистична; несколько разбиений не являются независимыми наборами молекул.

## Данные и предыдущая модель v2

- `train.csv`: 320 наблюдений, 312 уникальных канонических молекул.
- `test.csv`: 597 наблюдений; порядок `index` сохраняется по `sample_submit.csv`.
- Используются только дескрипторы RDKit, вычисленные из SMILES.
- `CC50_uM`, `IC50_uM_VACV`, `Title`, `strain`, `Culture` не входят в признаки.
- Модель: ExtraTrees, 350 деревьев, `min_samples_leaf=3`, `max_features=0.5`, seed 42. Пропуски дескрипторов заполняются внутри каждого обучающего fold.
- Предсказания ограничены снизу нулём. Цель не логарифмируется.

В ранних экспериментах сравнивались Morgan fingerprints разных радиусов, count fingerprints, RDK и MACCS, Tanimoto Kernel Ridge, ExtraTrees, Random Forest и HistGradientBoosting. Численные результаты сохранены в `experiments_v2.json`.

## Проверка качества

Основная проверка — 5-fold GroupKFold по каноническим SMILES на двух разбиениях, seed 42 и 2026. Одинаковые молекулы целиком остаются в одном fold. Оценка считается по MSE после всех преобразований в исходной шкале SI.

| Вес внешних наблюдений | MSE, seed 42 | MSE, seed 2026 | Средний MSE |
|---|---:|---:|---:|
| 0 — только соревнование | 13 909 341 | 13 750 241 | 13 829 791 |
| 0.1 | 14 189 162 | 14 253 922 | 14 221 542 |
| 0.3 | 14 870 529 | 15 350 888 | 15 110 708 |
| 1.0 | 18 560 082 | 20 932 693 | 19 746 388 |

Итоговый выбор — вес 0. Внешняя база собрана и проверена, но эта порция данных ухудшила валидацию. Файл `training_used.csv` фиксирует именно 320 строк, использованных для обучения выбранной модели.

Дополнительный scaffold split (`GroupKFold` без перемешивания) дал MSE **17 661 068**. Это показывает более слабый перенос на новые химические каркасы. Ранее в `results_v2.json` использовалось другое, перемешанное scaffold-разбиение; его значение напрямую с этим не сравнивается.

Выбор модели и веса выполнялся по тем же данным, на которых приведена CV-оценка; она оптимистична. Два разбиения не являются двумя независимыми наборами молекул. В данных 81 значение SI ровно 10 000, а некоторые повторные структуры имеют противоречивые ответы. Эти значения сохранены без предположения об их происхождении.

## Сборщик внешних данных

`collect_data.py` получает активности и библиографические записи из ChEMBL. В текущую базу входят две публикации:

1. [10.1039/d4md00181h](https://doi.org/10.1039/d4md00181h): VACV Copenhagen, Vero, IC50 и CC50 после 4 дней.
2. [10.1016/j.ejmech.2023.115601](https://doi.org/10.1016/j.ejmech.2023.115601): VACV, Vero и A549; опубликованный SI использует IC50 после 96 ч и CC50 после 72 ч. Эта разница сохранена в данных.

Результат: **63 записи**, из них **57** допущены к обучению по формальным проверкам; **39 уникальных SMILES**. После исключения пересечений с исходным train и агрегации повторных SMILES остаются 27 внешних молекул для эксперимента.

- `external_data.csv`: полная таблица `smiles`, `IC50`, `CC50`, `SI`, `doi`, условия, отношения, ChEMBL ID и ссылки на измерения.
- `external_training.csv`: только точные значения без выявленных проблем.
- `external_validation.json`: причины исключения и ограничения.
- `assay_mapping.json`: явное соответствие IC50, CC50 и SI assay для каждой публикации и клеточной линии.

SI берётся из опубликованного измерения. Отношение CC50/IC50 используется только для проверки округления. Концентрации приводятся к мкМ; EC50 не переименовывается в IC50. Значения `>`, `<` и другие границы не превращаются в точные ответы. Разные публикации, клеточные линии и assays автоматически не смешиваются.

Перед CV все внешние записи, совпадающие по каноническому SMILES с любой молекулой исходного train, исключаются. Для scaffold-проверки дополнительно исключаются внешние молекулы с каркасом validation. Внешние условия остаются в базе, но модель использует только SMILES; при нескольких допустимых внешних измерениях одного SMILES эксперимент использует среднее SI.
