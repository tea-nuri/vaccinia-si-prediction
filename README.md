# VACV SI — команда «Чай»

Предсказание индекса селективности по SMILES и разрешённому контексту для [соревнования Kaggle](https://www.kaggle.com/competitions/molecular-activity-prediction-hack). Выбрана лучшая подтверждённая версия **V5 Степана**: **Public MSE 5 148 656.84097**, подтверждён 6 ноября 2026. Её неизменённый CSV — `results/submission.csv` (на Kaggle назывался `submission_v5.csv`). Чем меньше MSE, тем лучше. Предыдущая V4: 5 154 554.48738; публичный выигрыш V5 небольшой, около 0.11%.

## Воспроизведение

V5 проверена на Python 3.14.5; точные версии библиотек указаны в `requirements.txt`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python collect_data.py --offline
python -m unittest test_validation.py -v
python train.py --output run
```

Обучение и проверка создают в `run/`: `submission.csv`, `model.joblib`, `training_used.csv`, `validation.csv`, `metrics.json`. CSV готов к загрузке на Kaggle. Быстрый запуск без повторной кросс-валидации: `python train.py --skip-cv --output run`. Тест воспроизводимости сравнивает все 597 предсказаний с выбранным сабмитом.

Обновление внешних данных из интернета: `python collect_data.py --refresh`. Обычный запуск работает без сети благодаря сохранённому снимку ChEMBL. Команда `--offline` восстанавливает базу и повторяет её проверку из этого снимка.

## Модель и проверка

Организаторы в переписке капитанов разрешили `strain` и `Culture` и пояснили, что SI=10 000 — условная метка неактивности против VACV при отсутствии IC50. Это не измеренный высокий SI и не основание автоматически удалять строки. Входные колонки ограничены списком `SMILES`, `strain`, `Culture`; CC50, IC50, признаки их пропусков, Title и index не используются.

V5 — равная смесь двух компонентов. Первый — прежняя модель V4: символьные n-граммы SMILES длины 2–6, TF-IDF с сохранением регистра и sublinear TF, Ridge (alpha=0.03), смешанный в пропорции 85/15 с ExtraTrees (500 деревьев, seed 42) по длине строки и количествам/позициям символов SMILES. К этому прогнозу применяется `clip((prediction - 5000) * 1.5 + 5000, 0, 10000)`.

Второй компонент — CatBoost-классификатор неактивности (700 итераций, глубина 5, learning rate 0.035, L2=5, seed 42), использующий счётчики SMILES и исходные категориальные strain/Culture. Отдельный ExtraTrees обучается только на активных строках и прогнозирует SI, ограниченный сверху 5000. Итог второго компонента: `10000 * P(inactive) + (1 - P(inactive)) * predicted_active_SI`. После этого два компонента усредняются с весами 50/50.

У первого компонента обучающая цель ограничена сверху 10 000; конечные прогнозы лежат в диапазоне 0–10 000. Файл `results/training_used.csv` фиксирует исходную цель, метку неактивности и обучающие цели регрессоров. **MSE считается по исходным, не обрезанным целям.** Все модели, словарь, IDF и обработка категорий обучаются внутри каждого fold. Повторы канонических молекул не пересекают train и validation.

| Проверка | MSE |
|---|---:|
| GroupKFold, seed 42 | 6 588 390 |
| GroupKFold, seed 2026 | 6 909 383 |
| GroupKFold, seed 117 | 6 217 197 |
| GroupKFold, seed 2027 | 6 918 997 |
| GroupKFold, seed 7 | 6 981 910 |
| Среднее пяти разбиений | 6 723 175 |
| Scaffold GroupKFold | 10 687 405 |
| Kaggle public | 5 148 656.84097 |

Модель и параметры выбраны на этом небольшом наборе, поэтому CV оптимистична. Исходная запись SMILES отражает соглашения источника; эквивалентные записи могут получать разные прогнозы. Ограничение цели может занижать действительно высокие SI. Public score не является оценкой скрытой части теста.

## Внешние данные

Сборщик использует шесть публикаций: [10.1039/d4md00181h](https://doi.org/10.1039/d4md00181h), [10.1016/j.ejmech.2023.115601](https://doi.org/10.1016/j.ejmech.2023.115601), [10.1016/j.bmcl.2022.129080](https://doi.org/10.1016/j.bmcl.2022.129080), [10.1039/d0md00108b](https://doi.org/10.1039/d0md00108b), [10.1039/C8MD00442K](https://doi.org/10.1039/C8MD00442K), [10.1021/jm301735k](https://doi.org/10.1021/jm301735k). База расширена с исходных 63 до **107 записей**; **98** проходят формальные проверки, **78 уникальных SMILES** среди допущенных записей. Готовая база хранится одним CSV; подходящие записи отмечены `usable_for_training`. Снимок API расширен, URL и SHA-256 сохранены; повторная сборка проверяет целостность снимка.

Для трёх новых публикаций явно выбраны согласованные assays VACV Copenhagen / Vero. Также сохранено дополнение команды по VACV WR / BSC1 из публикации 2013 года; разница IC50 overnight / CC50 20 h указана в базе. Данные других вирусов из тех же статей исключены. В одной новой записи SI расходится с отношением концентраций примерно в тысячу раз: исходные значения сохранены, запись помечена и исключена из обучения. Данные с отсутствующим SI и результаты «нет активности» не превращаются автоматически в измеренный SI=10000.

Проверены также дополнительные публикации о сердечных гликозидах, камфене и cage–amide соединениях. Поиск по DOI в ChEMBL не дал готовых записей для этой итерации; такие источники требуют отдельного извлечения структур и таблиц. Они не включены в счётчик базы.

Сохраняются клеточная линия, штамм, время, отношения измерений, assay/activity ID и DOI. Опубликованный SI не подменяется автоматически вычисленным отношением: CC50/IC50 служит проверкой согласованности. Границы `>`/`<` не превращаются в точные значения; EC50 не переименовывается в IC50; неоднозначные пары вызывают ошибку. Для публикации 2023 года сохранена разница времени измерений CC50 (72 ч) и IC50 (96 ч).

**Выбранная лучшая модель обучена только на 320 исходных строках.** Фактический состав обучения зафиксирован в `results/training_used.csv`. Добавление расширенной внешней базы теперь проверяется на текущем V5 одной командой:

```bash
python train.py --external-ablation --output run_external
```

Отчёт — `run_external/external_experiment.json`; проверенный результат сохранён в `results/external_experiment.json`. Перед CV исключаются все внешние молекулы, совпадающие с любой молекулой исходного train, в том числе после удаления противоионов и нейтрализации с сохранением стереохимии. Остаются **77 наблюдений по 61 новой структуре**. На scaffold-разбиении дополнительно исключаются каркасы validation. Разные экспериментальные контексты не усредняются; суммарный вес внешней молекулы делится между её измерениями. Все компоненты V5 получают те же исходные параметры, а поддерживающие веса модели используют только признаки из разрешённого списка.

| Вес внешней молекулы | MSE seed 42 | MSE seed 2026 | MSE по новым каркасам |
|---|---:|---:|---:|
| 0 — текущий V5 | 6 588 390 | 6 909 383 | 10 687 405 |
| 0,1 | 6 857 014 | 6 916 330 | 10 724 434 |
| 0,3 | 6 917 084 | 6 983 460 | 10 442 738 |
| 1 | 6 780 012 | 6 964 252 | 10 391 042 |

Правило выбора задано до проверки: новый вес должен улучшить оба молекулярных разбиения и scaffold-разбиение. Ни один вес не прошёл; рекомендован вес 0. При весах 0,3 и 1 перенос на новые каркасы немного улучшился, оба молекулярных разбиения ухудшились при всех проверенных весах. Поэтому выбранный Kaggle-сабмит и его метрики сохранены. Внешняя порция содержит точные измеренные SI и не покрывает группу неактивности с sentinel=10000; её состав отличается от исходного train. Результат не доказывает бесполезность всех внешних данных. CV повторно использует уже исследованные молекулы и не является независимой оценкой.

Команда сохраняет OOF-прогнозы, модель, фактический обучающий набор и CSV выбранного варианта в игнорируемом `run_external/`. Эксперимент с внешними данными полностью воспроизводим; файлы лучшего решения в `results/` автоматически не заменяются.
