# VACV SI — команда «Чай»

Предсказание индекса селективности по SMILES, разрешённому контексту и открытым данным для [соревнования Kaggle](https://www.kaggle.com/competitions/molecular-activity-prediction-hack). Лучшая подтверждённая версия **V6 Степана: Public MSE 5 144 257.81271**, подтверждена 6 ноября 2026. Загруженный CSV сохранён без изменений в `results/submission.csv` (на Kaggle — `submission_v6.csv`). Чем меньше MSE, тем лучше. Предыдущая V5: 5 148 656.84097; выигрыш составляет около 0.085%. Описание метода добавлено к сабмиту.

## Воспроизведение

V6 проверена на Python 3.14.5; точные версии библиотек указаны в `requirements.txt`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python collect_data.py --offline
python -m unittest test_validation.py -v
python train.py --output run
```

Обучение и проверка создают в `run/`: `submission.csv`, `model.joblib`, `training_used.csv`, `validation.csv`, `metrics.json`. CSV готов к загрузке на Kaggle. Быстрый запуск без повторной кросс-валидации: `python train.py --skip-cv --output run`. Тест воспроизводимости сравнивает все 597 предсказаний с выбранным сабмитом.

Обновление внешних данных из интернета: `python collect_data.py --refresh`. Обычный запуск работает без сети благодаря сохранённому снимку ChEMBL. Команда `--offline` восстанавливает базу и повторяет её проверку из этого снимка.

## Модель и проверка

Организаторы в переписке капитанов разрешили `strain` и `Culture` и пояснили, что SI=10 000 — условная метка неактивности против VACV при отсутствии IC50. Это не измеренный высокий SI и не основание автоматически удалять строки. Входные колонки ограничены списком `SMILES`, `strain`, `Culture`; CC50, IC50, признаки их пропусков, Title и index не используются.

Основа V6 — модель V5, равная смесь двух компонентов. Первый — прежняя модель V4: символьные n-граммы SMILES длины 2–6, TF-IDF с сохранением регистра и sublinear TF, Ridge (alpha=0.03), смешанный в пропорции 85/15 с ExtraTrees (500 деревьев, seed 42) по длине строки и количествам/позициям символов SMILES. К этому прогнозу применяется `clip((prediction - 5000) * 1.5 + 5000, 0, 10000)`.

Второй компонент — CatBoost-классификатор неактивности (700 итераций, глубина 5, learning rate 0.035, L2=5, seed 42), использующий счётчики SMILES и исходные категориальные strain/Culture. Отдельный ExtraTrees обучается только на активных строках и прогнозирует SI, ограниченный сверху 5000. Итог второго компонента: `10000 * P(inactive) + (1 - P(inactive)) * predicted_active_SI`. После этого два компонента усредняются с весами 50/50.

V6 дополняет этот прогноз проверяемой коррекцией: ищет точное совпадение канонического SMILES с явным внешним исходом `Not active` против VACV. Молекулы, встречающиеся в нескольких публикациях VACV, исключаются из коррекции. Для каждой культуры правило дополнительно требует не менее трёх обучающих строк с таким свидетельством и SI=10 000 у всех этих строк. Только тогда прогноз совпавшей тестовой молекулы становится 10 000. Соответствие культуре обучается заново внутри каждого fold; целевые значения validation/test ему не доступны. В финальном тесте правило затронуло 46 строк. Внешние концентрации и их пропуски не входят в признаки модели.

У первого компонента обучающая цель ограничена сверху 10 000; конечные прогнозы лежат в диапазоне 0–10 000. Файл `results/training_used.csv` фиксирует исходную цель, метку неактивности и обучающие цели регрессоров. **MSE считается по исходным, не обрезанным целям.** Все модели, словарь, IDF и обработка категорий обучаются внутри каждого fold. Повторы канонических молекул не пересекают train и validation.

| Проверка | MSE |
|---|---:|
| GroupKFold, seed 42 | 6 541 601 |
| GroupKFold, seed 2026 | 6 808 111 |
| GroupKFold, seed 117 | 6 183 182 |

Модель и параметры выбраны на этом небольшом наборе, поэтому CV оптимистична. Исходная запись SMILES отражает соглашения источника; эквивалентные записи могут получать разные прогнозы. Ограничение цели может занижать действительно высокие SI. Public score не является оценкой скрытой части теста.

## Внешние данные

Сборщик использует четыре публикации: [10.1039/d4md00181h](https://doi.org/10.1039/d4md00181h) и [10.1016/j.ejmech.2023.115601](https://doi.org/10.1016/j.ejmech.2023.115601), [10.1039/C8MD00442K](https://doi.org/10.1039/C8MD00442K) и [10.1021/jm301735k](https://doi.org/10.1021/jm301735k). Собраны 75 записей, 67 проходят формальные проверки, 49 уникальных SMILES среди допущенных записей. Готовая база хранится одним CSV; подходящие записи отмечены `usable_for_training`.

Сохраняются клеточная линия, штамм, время, отношения измерений, assay/activity ID и DOI. Опубликованный SI не подменяется автоматически вычисленным отношением: CC50/IC50 служит проверкой согласованности. Границы `>`/`<` не превращаются в точные значения; EC50 не переименовывается в IC50; неоднозначные пары вызывают ошибку. Для публикации 2023 года сохранена разница времени измерений CC50 (72 ч) и IC50 (96 ч). Для публикации 2013 года сохранены IC50 после ночной инкубации и CC50 через 20 ч. Пропущенный IC50/SI не преобразуется в метку неактивности.

**Численные цели обучения по-прежнему взяты из 320 исходных строк.** Добавление внешних численных SI и несколько вариантов расширения моделей не улучшили выбранную валидацию. V6 использует внешние качественные свидетельства как дополнительную информацию для описанной выше коррекции. Фактические цели и признаки свидетельств зафиксированы в `results/training_used.csv`.

Дополнительно просмотрены 4 849 записей ChEMBL по VACV и сохранены **1 116 явных отметок неактивности из 85 публикаций**, 1 050 уникальных SMILES. У 1 026 молекул только один источник VACV. Учитываются поля `activity_comment`, `standard_text_value` и `text_value`. Отметки цитотоксичности/CC50/MCC50 исключены, отсутствующие измерения не превращаются в неактивность. Полные ответы источника сохранены для повторной проверки пагинации, DOI, признака нескольких источников и извлечённых исходов. Эти наблюдения не являются автоматически новыми целями SI.

Сводка новых экспериментов находится в `results/experiments_external.json`: признаки публикаций, отдельные классификаторы неактивности, расширение внешними активными соединениями, Morgan/символьные признаки и варианты коррекции. Ограничение источника важно: без него внешние данные давали ложные исправления из-за различий между опытами. Валидация V6 использует те же малые разбиения, на которых принимались решения, поэтому оценка выигрыша оптимистична.
