# VACV SI — команда «Чай»

Предсказание индекса селективности по SMILES, разрешённому контексту и открытым данным для [соревнования Kaggle](https://www.kaggle.com/competitions/molecular-activity-prediction-hack). Лучшая подтверждённая версия **V7 Степана: Public MSE 3 783 018.17208**, подтверждена 6 ноября 2026. Загруженный CSV сохранён без изменений в `results/submission.csv` (на Kaggle — `submission_v7.csv`). Чем меньше MSE, тем лучше. Предыдущая V6: 5 144 257.81271; ошибка снизилась на 26.46%. На момент проверки команда занимает 6-е место. Описание метода добавлено к сабмиту.

## Воспроизведение

V7 проверена на Python 3.14.5; точные версии библиотек указаны в `requirements.txt`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python collect_data.py --offline
python collect_literature.py
python -m unittest test_validation.py test_literature.py -v
python train.py --output run
```

Обучение и проверка создают в `run/`: `submission.csv`, `model.joblib`, `training_used.csv`, `validation.csv`, `metrics.json`, `test_lookup_audit.csv`. CSV готов к загрузке на Kaggle. Быстрый запуск без повторной кросс-валидации: `python train.py --skip-cv --output run`. Тест воспроизводимости сравнивает все 597 предсказаний с выбранным сабмитом.

Обновление внешних данных из интернета: `python collect_data.py --refresh`. Обычный запуск работает без сети благодаря сохранённому снимку ChEMBL. Команда `--offline` восстанавливает базу и повторяет её проверку из этого снимка.

## V7: проверка первичных статей

**V7 уже отправлена Степаном: Public MSE 3 783 018.17208**, проверено на странице Kaggle Submissions 6 ноября. Улучшение относительно V6 — 26,46%. Повторная отправка при проверке экспериментов не выполнялась. CSV и метрики в `results/` обновлены до подтверждённой V7; основной запуск воспроизводит её.

Добавлены `collect_literature.py`, `literature.py` и отдельная база `data/primary_literature.csv`: **89 записей из 4 первичных статей**, 63 допущены к сопоставлению. Сборщик воспроизводит ручную транскрипцию таблиц и перевод опубликованных названий/схем в SMILES; он не читает файлы соревнования. DOI, номер соединения, исходный endpoint, границы и опубликованный SI сохранены. Проверены формулы и абсолютная конфигурация названных стереоцентров. `data/primary_structure_evidence.json` содержит независимое подтверждение структуры камфорного соединения 8e из ChEMBL.

```bash
python collect_literature.py
python -m unittest test_validation.py test_literature.py -v
python train.py --literature-ablation --output run_literature_v7
```

Эксперимент заново строит V6 на пяти разбиениях по молекулам и одном по каркасам, затем применяет внешние измерения при совпадении структуры и клеточного контекста. Средний MSE на пяти разбиениях: **6 668 136 → 1 499 325**; scaffold MSE: **10 650 743 → 5 686 744**. Найдены соответствия для **45 из 320** обучающих и **95 из 597** тестовых строк. Отчёт — `results/literature_experiment.json`; полный аудит каждого совпадения и кандидат CSV создаются в `run_literature_v7/`. После подтверждения Public MSE **3 783 018.17208** V7 стала основной версией в `train.py` и `results/`. Обычный запуск воспроизводит именно V7; флаг `--literature-ablation` отдельно пересчитывает базовую V6 и эффект добавления литературы.

Это **retrieval-assisted оценка для молекул с опубликованными результатами**, а не проверка обобщения на новые молекулы без внешних измерений. Существенную долю выигрыша даёт один большой обучающий SI. Для строк без совпадений прогноз и качество базовой модели не изменяются. Поиск источников и выбор политики уже учитывали обучающие ошибки; локальный выигрыш не гарантирует такой же public/private score.

Особенности проверки источников:

- [Chemistry 2025, Table 1](https://doi.org/10.3390/chemistry7020034): 16 соединений, исходный EC50 сохранён отдельно от IC50. Для опубликованных смесей стереоизомеров допускается совпадение связности; это правило ограничено этой статьёй. В [cage–amide статье](https://doi.org/10.3390/v15010029) аналогичное сопоставление используется для ахиральных адамантановых структур.
- [ChemMedChem 2022, Table 1](https://doi.org/10.1002/cmdc.202100771): точная стереохимия камфорных амидов сохранена. Названия 8b/c/e в экспериментальной части принятой рукописи противоречат общему коду заместителей. Для 8e нитроструктура и все три противовирусных измерения дополнительно подтверждены CHEMBL5410209 (DOI 10.1021/acs.jmedchem.3c00069); 8b/c не включены. Серии 9/10 записаны, но исключены из коррекции до разрешения стереохимических расхождений.
- [BMCL 2023, Table 1](https://doi.org/10.1016/j.bmcl.2022.129080): в первичной статье указан 4-метильный имидазол, тогда как соответствующая запись ChEMBL содержит 4-гидроксильный заместитель. В новой базе использована структура первоисточника; исходный снимок ChEMBL не переписан.
- В эксперименте используется отношение **внешних** округлённых средних концентраций из согласованных assays/строк таблицы. Опубликованный SI сохраняется отдельно, включая расхождения. Концентрации и их пропуски из файлов соревнования не читаются. Явное `NA = not active` интерпретируется по разъяснению организаторов как sentinel 10000; пустое поле само по себе таким свидетельством не является.

## Проверка дополнительных моделей поверх V7

`python experiments/activity_heads.py` сравнивает шесть классификаторов неактивности (символьная логистическая регрессия, гибридный SVM с Morgan/TF-IDF/контекстом и Morgan CatBoost), каждый с тремя весами смешивания. Проверены seed 42, seed 2026 и scaffold. Литературные совпадения одинаковы у всех кандидатов; модели меняют только остальные прогнозы. Все словари и кодировщики обучаются внутри fold, коррекция V6 по внешней неактивности сохраняется. Результаты — `results/activity_diagnostics.json`; подробные OOF создаются в игнорируемом `run_heads/`.

Ни один из 18 вариантов не улучшил все три протокола ни на V6, ни поверх V7. Например, text C=100 с весом 0,25 поверх V7 даёт 1 448 819 / 1 491 089 / 5 510 944 против 1 357 442 / 1 539 877 / 5 686 744 у V7. Подтверждённая V7 выбрана без этих добавок. Это повторное исследование уже изученных данных, а не независимый holdout.

Дополнительный `python train.py --known-compounds --output run_known` включает экспериментальную коррекцию по точной канонической структуре со стереохимией и совпадающему нормализованному штамму/клеткам из train. Конфликты и неизвестный контекст дают возврат к модели. При разбиении по молекулам совпадений нет, поэтому такой CV не подтверждает пользу этой коррекции; она выключена по умолчанию и не включена в подтверждённый сабмит V7. При явном флаге эта коррекция применяется поверх V7.

Попытки Kaggle расходуются на существенные устойчивые локальные улучшения; небольшие или противоречивые изменения остаются локальными экспериментами.

## Модель и проверка

Организаторы в переписке капитанов разрешили `strain` и `Culture` и пояснили, что SI=10 000 — условная метка неактивности против VACV при отсутствии IC50. Это не измеренный высокий SI и не основание автоматически удалять строки. Входные колонки ограничены списком `SMILES`, `strain`, `Culture`; CC50 и IC50 из файлов соревнования, признаки их пропусков, Title и index не используются. Внешние опубликованные измерения применяются отдельно, по описанным правилам V7.

Основа V6 — модель V5, равная смесь двух компонентов. Первый — прежняя модель V4: символьные n-граммы SMILES длины 2–6, TF-IDF с сохранением регистра и sublinear TF, Ridge (alpha=0.03), смешанный в пропорции 85/15 с ExtraTrees (500 деревьев, seed 42) по длине строки и количествам/позициям символов SMILES. К этому прогнозу применяется `clip((prediction - 5000) * 1.5 + 5000, 0, 10000)`.

Второй компонент — CatBoost-классификатор неактивности (700 итераций, глубина 5, learning rate 0.035, L2=5, seed 42), использующий счётчики SMILES и исходные категориальные strain/Culture. Отдельный ExtraTrees обучается только на активных строках и прогнозирует SI, ограниченный сверху 5000. Итог второго компонента: `10000 * P(inactive) + (1 - P(inactive)) * predicted_active_SI`. После этого два компонента усредняются с весами 50/50.

V6 дополняет этот прогноз проверяемой коррекцией: ищет точное совпадение канонического SMILES с явным внешним исходом `Not active` против VACV. Молекулы, встречающиеся в нескольких публикациях VACV, исключаются из коррекции. Для каждой культуры правило дополнительно требует не менее трёх обучающих строк с таким свидетельством и SI=10 000 у всех этих строк. Только тогда прогноз совпавшей тестовой молекулы становится 10 000. Соответствие культуре обучается заново внутри каждого fold; целевые значения validation/test ему не доступны. В финальном тесте правило затронуло 46 строк. Внешние концентрации и их пропуски не входят в признаки модели.

V7 применяет описанное выше сопоставление с первичными измерениями и согласованными внешними assay-парами поверх V6. Для 95 тестовых строк прогноз заменяется внешним значением; остальные прогнозы сохраняются. У первого компонента обучающая цель ограничена сверху 10 000; прогноз базовой V6 лежит в диапазоне 0–10 000, но внешние измеренные значения V7 сверху не обрезаются. Файл `results/training_used.csv` фиксирует исходную цель, метку неактивности и обучающие цели регрессоров. **MSE считается по исходным, не обрезанным целям.** Все модели, словарь, IDF и обработка категорий обучаются внутри каждого fold. Повторы канонических молекул не пересекают train и validation базовых моделей. При этом фиксированная внешняя база может содержать измерения для validation-молекул: оценка V7 включает восстановление таких известных измерений.

| Проверка | MSE |
|---|---:|
| GroupKFold, seed 42 | 1 357 442 |
| GroupKFold, seed 2026 | 1 539 877 |
| GroupKFold, seed 117 | 1 445 965 |
| GroupKFold, seed 2027 | 1 524 010 |
| GroupKFold, seed 7 | 1 629 330 |
| Среднее пяти разбиений | 1 499 325 |
| Scaffold GroupKFold | 5 686 744 |
| Kaggle public | 3 783 018.17208 |

Модель и параметры выбраны на этом небольшом наборе, поэтому CV оптимистична. Исходная запись SMILES отражает соглашения источника; эквивалентные записи могут получать разные прогнозы. Ограничение цели может занижать действительно высокие SI. Public score не является оценкой скрытой части теста.

## Внешние данные

Сборщик использует девять публикаций: [10.1039/d4md00181h](https://doi.org/10.1039/d4md00181h), [10.1016/j.ejmech.2023.115601](https://doi.org/10.1016/j.ejmech.2023.115601), [10.1016/j.bmcl.2022.129080](https://doi.org/10.1016/j.bmcl.2022.129080), [10.1039/d0md00108b](https://doi.org/10.1039/d0md00108b), [10.1039/C8MD00442K](https://doi.org/10.1039/C8MD00442K), [10.1021/jm301735k](https://doi.org/10.1021/jm301735k), [10.1039/C8MD00347E](https://doi.org/10.1039/C8MD00347E), [10.1016/j.ejmech.2021.113485](https://doi.org/10.1016/j.ejmech.2021.113485), [10.1016/j.bmcl.2017.06.035](https://doi.org/10.1016/j.bmcl.2017.06.035). База расширена со 107 до **221 записи**; **114** проходят формальные проверки (ранее 98), **93 уникальных SMILES** среди допущенных записей (ранее 78). Готовая база хранится одним CSV; подходящие записи отмечены `usable_for_training`. Снимок API расширен, URL и SHA-256 сохранены; повторная сборка проверяет целостность снимка.

Последнее расширение добавляет три источника:

| DOI | Записей VACV | Допущено как точный SI |
|---|---:|---:|
| 10.1039/C8MD00347E | 19 | 11 |
| 10.1016/j.ejmech.2021.113485 | 19 | 5 |
| 10.1016/j.bmcl.2017.06.035 | 5 | 0 |

Новые источники дали 43 записи, из них 16 допущены. Ещё 71 ранее пропущенная запись из прежних источников сохранена для аудита: сборщик теперь берёт объединение молекул из IC50 и SI assays. Пропуски, границы и несогласованные отношения исключены из численного обучения. В статье 2018 года TC50 обозначает клеточную токсичность и сопоставлен с CC50 только для явно выбранного assay. Исходные названия показателей и текстовые поля сохраняются в CSV. В статье 2017 года четыре SI не согласуются с CC50/IC50, пятая запись содержит границы; все пять исключены из обучения.

Для источников Copenhagen / Vero явно выбраны согласованные assays. Также сохранено дополнение команды по VACV WR / BSC1 из публикации 2013 года; разница IC50 overnight / CC50 20 h указана в базе. Данные других вирусов из тех же статей исключены. В одной новой записи SI расходится с отношением концентраций примерно в тысячу раз: исходные значения сохранены, запись помечена и исключена из обучения. Данные с отсутствующим SI и результаты «нет активности» не превращаются автоматически в измеренный SI=10000.

**Численные цели обучения по-прежнему взяты из 320 исходных строк.** Добавление внешних численных SI и несколько вариантов расширения моделей не улучшили выбранную валидацию. V6 использует внешние качественные свидетельства, а V7 дополнительно восстанавливает опубликованные численные измерения для совпавших молекул. Эти внешние значения не подменяют обучающие цели базовой модели. Фактические цели и признаки свидетельств зафиксированы в `results/training_used.csv`.

Дополнительно просмотрены 4 849 записей ChEMBL по VACV и сохранены **1 116 явных отметок неактивности из 85 публикаций**, 1 050 уникальных SMILES. У 1 026 молекул только один источник VACV. Учитываются поля `activity_comment`, `standard_text_value` и `text_value`. Отметки цитотоксичности/CC50/MCC50 исключены, отсутствующие измерения не превращаются в неактивность. Полные ответы источника сохранены для повторной проверки пагинации, DOI, признака нескольких источников и извлечённых исходов. Эти наблюдения не являются автоматически новыми целями SI.

Сводка новых экспериментов находится в `results/experiments_external.json`: признаки публикаций, отдельные классификаторы неактивности, расширение внешними активными соединениями, Morgan/символьные признаки и варианты коррекции. Ограничение источника важно: без него внешние данные давали ложные исправления из-за различий между опытами. Валидация V6 использует те же малые разбиения, на которых принимались решения, поэтому оценка выигрыша оптимистична.

Для cage–amide соединений отсутствие готовых записей ChEMBL устранено ручным извлечением первичной таблицы в базе V7. Дополнительные публикации о сердечных гликозидах и камфене пока не включены в базу.

Сохраняются клеточная линия, штамм, время, отношения измерений, assay/activity ID и DOI. В численном сборщике ChEMBL опубликованный SI сохраняется, а CC50/IC50 служит проверкой согласованности. Отдельный слой V7 явно использует отношение внешних округлённых концентраций, сохраняя опубликованный SI для аудита. Границы `>`/`<` не превращаются в точные значения; EC50 не переименовывается в IC50; неоднозначные пары вызывают ошибку. Для публикации 2023 года сохранена разница времени измерений CC50 (72 ч) и IC50 (96 ч).

Добавление расширенной численной базы можно проверить на текущей выбранной модели одной командой:

```bash
python train.py --external-ablation --output run_external
```

## Собственное улучшение кандидата команды

Основа сравнения — локальный кандидат сокомандника `results/candidate_literature2019.csv`, средний MSE которого на пяти молекулярных разбиениях равен 1 006 918. Новые изменения: проверка происхождения численного литературного измерения и фиксированная калибровка модели: Ridge alpha=0,003, наклон SMILES-компонента=2, степень odds классификатора=1,5. Правило читает дополнительные виды вирусов из разрешённого `strain` и проверяет, перечислены ли они в assays хотя бы одного подходящего источника. При неподтверждённом контексте кандидат отказывается от численной ChEMBL-подстановки и использует прогноз модели, обученной внутри fold. Это консервативный сигнал происхождения, а не доказательство ошибочности публикации. Первичные таблицы остаются вне этого правила. Исключений по номеру строки, структуре или SI нет. Покрытие источников извлекается из проверенного SHA-256 снимка; цели и концентрации соревнования не участвуют в решении.
